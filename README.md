# Project.天台

**定位**：第一人称不对称射击恐怖游戏（PvPvE）
**引擎**：Unity 6000.6.7f1（URP 17.6.0）｜ **网络**：FishNet + Tugboat(TCP)｜ **开源**：AGPL-3.0

---

## 一、游戏设计文档（完整）

### 1. 阵营分化

**人类（默认 5 名，从 8 名角色池中选出）**

| 职业 | 人数 | 专属道具 / 能力 |
|---|---|---|
| 员工 | 1 | 钥匙（不限次开上锁门）· 轻车熟路（奔跑 +10%） |
| 工人·弟弟 | 1 | 接线钳（电气专家：修电闸更快且免零件） |
| 工人·哥哥 | 1 | 扳手（把上锁门**永久**撬成普通门） |
| 博士 | 1 | 特制紫外线枪（丧尸僵直+闪光，限次）· 病毒血清（解除感染，限次） |
| 学生 | 4 | 无专属道具（基础人类） |

**丧尸（默认 1 名玩家丧尸 + 若干人机丧尸）**

| 类型 | 说明 |
|---|---|
| 玩家丧尸 | 初始 1 只；攻击人类必然触发**感染**；可**标记**视野内人类（提升人机丧尸对目标的仇恨→集火）；视野受限（迷雾）；被击杀后**弱化重生**（无标记），吃回自己尸体恢复能力 |
| 人机丧尸 | 由玩家丧尸转化尸体/自动刷新；智力低，**只能在出生点区域小范围游荡**（区域束缚）；仇恨系统驱动追击；攻击也触发感染 |

### 2. 游戏机制

- **感染机制**：任意丧尸近战命中人类 → 感染（全程无法行动/无法被攻击，播放 CG 占位）→ 30s 倒计时内被博士血清解除则恢复，否则转化为玩家丧尸（同客户端转职）。
- **死亡机制**：人类 HP 归零（主要来自友伤枪弹）→ 变**尸体** + **幽灵观战**；玩家丧尸可**啃咬尸体** → 该观战玩家转玩家丧尸。
- **撤离机制**：天台电台（默认完好），人类 E 键呼叫救援 → **30s 倒计时** → 撤离区 **3 个座位先到先得**；有人登机 ⇒ 登机者胜/未登机者败/丧尸败；无人登机 ⇒ 丧尸胜。
- **战斗机制**：枪弹可同时伤害人类（友伤）与丧尸；爆头大量伤害、身体减半；受猛烈攻击短暂减速后恢复。
- **声音/仇恨**：走路/跑步/枪声/落地由服务器计算，人机丧尸按**声音距离衰减**积累仇恨（走路极小，贴 1 米走约 20s 才会被抓）；无遮挡**视线**也缓慢增加仇恨；**指数衰减**+双阈值迟滞防止抽搐；玩家丧尸标记=把目标仇恨推到标记值→短暂集火。
- **门**：普通门上锁门两种；上锁门员工钥匙可开（打开不自动关，被关闭后重新锁上）；工人哥哥撬开→永久转普通门。
- **观战**：死亡人类进入幽灵观战——无碰撞/无建模/无声/隐形；WASD 自由飞行、滚轮切换玩家、左键附身、右键退出；被啃时**固定视角看自己尸体**；观战/转化后禁语音（语音权限字段预留）。

### 3. 特殊模式（规划内，暂未实现）

- 隐藏感染者（硬核）/ 团结一致 / 灭口小队 —— 均**未实现**，列为后续阶段。

## 二、技术架构

```
一份 exe，靠启动参数切换角色（核心原则：一切游戏计算默认在服务器）
```

| 系统 | 执行方 |
|---|---|
| 移动/跳跃/镜头 | 客户端（owner 本地计算，客户端权威） |
| 脚步声判定/声音事件 | 服务器 |
| 开枪判定/伤害/爆头 | 服务器 |
| 人机丧尸 AI（仇恨/索敌/追击） | 服务器 |
| 血量/死亡/尸体/感染/转化 | 服务器 |
| 角色分配/回合状态机/撤离/胜负 | 服务器 |
| 门/电闸/电梯/电台状态 | 服务器 |
| 本地 UI / 音效 / 迷雾 / 观战相机 | 客户端 |

**通信机制**：`ServerRpc`（客户端→服务器请求）、`ObserversRpc/TargetRpc`（服务器→客户端通知）、`Broadcast`（版本认证/大厅状态/回合状态/声音事件）、`NetworkTransform`（玩家=客户端权威，僵尸=服务器权威）。

## 三、如何运行

### 1. 构建

编辑器打开项目后：
- 菜单 **Tools → Build Network Prefabs**（首次/改预制体后）
- 菜单 **Tools → Build Game Scene**（首次/改场景后）
- 菜单 **Tools → Build Windows**（产出 `Builds/Rooftop.exe`，绝对路径）

### 2. 启动参数（一份构建三角色）

| 参数 | 作用 |
|---|---|
| `-server -batchmode -nographics` | 专用服务器（headless，只跑逻辑） |
| `-host` | 房主（服务器+客户端同进程） |
| `-join <IP>` | 客户端（采集输入/渲染/音效） |
| `-autotest` | 客户端自动移动/开枪（压测用） |
| `-autostart` | 服务器满员立即自动分配开局 |
| `-role human\|zombie\|auto` | 预选角色（预留） |
| `-port <端口>` | 指定端口（默认 7770） |

**示例**：
```powershell
Builds\Rooftop.exe -server -batchmode -nographics -autostart -logFile srv.log
Builds\Rooftop.exe -host
Builds\Rooftop.exe -join 127.0.0.1 -autotest
Builds\Rooftop.exe -join 127.0.0.1
```

### 3. 常见问题

- **服务器起不来 / Bind exception**：端口被旧进程/编辑器占用 → 关掉占用进程，或 `-port 换端口`。
- **大厅满员不开局**：已做 15s 安全自动开局；也可点「立即开始」按钮强制开局。
- **双 AudioListener / 65533 报错**：均已规避（菜单相机不挂监听、Tugboat TCP 替代 Synapse UDP）。

## 五、具体玩法（操作说明）

### 人类（员工/弟弟/哥哥/博士/学生）
| 按键 | 动作 |
|---|---|
| WASD | 移动 |
| Shift | 跑步 |
| 空格 | 跳跃 |
| 鼠标 | 视角 |
| 左键 | 开枪（服务器判定命中/爆头） |
| E | 交互：开门/关门、员工钥匙、哥哥撬门、呼叫救援 |
| 鼠标右键（博士） | 紫外线枪（对丧尸僵直，限次） |
| G（博士） | 血清（解除感染者，限次） |
| Esc | 解锁/锁定鼠标 |

**玩法**：找零件修电台（阶段三）→ 呼叫救援 → 3 人撤离即赢。小心友伤、人机丧尸按声音追你（安静+躲墙后最安全）、玩家丧尸会标记你让人机集火、被抓=感染=30s 后变丧尸。

### 玩家丧尸
| 按键 | 动作 |
|---|---|
| WASD/Shift/空格 | 移动/跑/跳（速度约 125% 人类） |
| 左键 | 近战（命中人类→感染） |
| F | 标记视野内人类（冷却，需先吃回自己尸体才有） |
| E | 啃尸体（人类尸体→该玩家转丧尸；自己的尸体→恢复标记能力） |

**玩法**：感染人类让他们 30s 后加入丧尸阵营；标记制造人机集火；被击杀后弱化重生（无标记），去找并吃掉自己的尸体恢复能力；人类开枪会暴露位置（屏幕方向箭头）。

### 幽灵观战（死亡后）
| 按键 | 动作 |
|---|---|
| WASD / 空格 / Shift | 自由飞行（穿墙，隐形无声） |
| 滚轮 | 在存活玩家间切换 |
| 左键 | 附身到该玩家视角 |
| 右键 | 退出附身 |

被玩家丧尸啃咬时：**固定视角看自己的尸体** → 转化为玩家丧尸继续游戏。
